## Como baixar

1. Abra a seção **[Releases](../../releases)**, na lateral direita desta página.
2. Escolha o jogo, o disco e a versão.
3. Em **Assets**, baixe o arquivo `.dcp` e o `LEIA_ME.txt`.

Cada pasta de jogo tem o `LEIA_ME.txt` com os requisitos e o passo a passo para aplicar o patch.

## Encontrou um erro?

Abra uma **[issue](../../issues/new/choose)** com o jogo, o disco, a versão do patch, o local ou personagem e, se possível, um print da tela.
Também dá para mandar pelo Instagram [@matrixoldgames](https://instagram.com/matrixoldgames) ou pelo e-mail matrixoldgames@gmail.com.

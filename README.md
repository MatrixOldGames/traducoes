# Matrix Old Games — Traduções

Patches de tradução para português do Brasil de jogos clássicos, feitos por fãs e sem fins lucrativos.

Site do projeto: **https://www.matrixoldgames.com.br**

> Este repositório tem **apenas patches de tradução**. Nenhum jogo é distribuído aqui.
> Para jogar, você precisa da sua própria cópia do jogo original.

## Como baixar

1. Na tabela acima, clique em **Baixar** na linha do jogo. O link abre direto a versão mais recente.
2. Em **Assets**, baixe o arquivo `.dcp` de cada disco e o `LEIA_ME.txt`.
3. Versões antigas continuam na seção **[Releases](../../releases)**.

Cada pasta de jogo tem o `LEIA_ME.txt` com os requisitos e o passo a passo para aplicar o patch.
